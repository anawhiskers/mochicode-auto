# Generic coding-agent adapter

Use the explicit Markdown instruction file documented by the installed coding agent and pass it with `--target`. Map **Authority/Parent** and **Routine worker** to models that the provider currently exposes, but keep the shared workflow unchanged. If the agent cannot prove child model identity or does not support child routing, keep work with the parent and never claim a worker model. Do not copy another provider's authentication, hooks, permissions, private endpoints, or machine-specific settings.
